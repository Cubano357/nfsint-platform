# NFSINT Website Rebuild
### Project Plan Summary — Phase 1: Frontend Rebuild

**Prepared for:** Brother Amari Bae, NFSINT
**Date:** September 30, 2026

---

## Why This Phase

The current NFSINT website is built on a no-code platform (SuperCool). It looks good, but NFSINT doesn't own the underlying code — it's locked into that platform's hosting, pricing, and limitations. This phase rebuilds the same site, page for page, in standard, professional, fully-owned source code. Nothing changes for a visitor; everything changes for NFSINT's long-term control over its own website.

## What's Included

All 9 pages of the current site, rebuilt to match exactly:

| Page | Content |
|---|---|
| Home | Mission overview, four core pillars, planned products |
| Mission | Mission statement, the four-pillar framework, long-term vision |
| About | Organizational status, FAQ, leadership placeholders |
| Intelligence | How information is collected, analyzed, and published |
| Research | Research approach and the eight active areas of study |
| Technology | The planned technology platform and its capabilities |
| Programs | Education and professional development programs |
| Partners | Partnership and investment information |
| Contact | General inquiry form |

Every heading, paragraph, and list is being carried over exactly as written today — this phase is a rebuild, not a rewrite. The visual design (navy and gold color scheme, layout, imagery) is being matched as closely as code allows.

## What This Phase Does *Not* Include

To keep this phase focused and deliverable, the following are intentionally **not** part of this rebuild — they're already planned as their own future phases:

- A working contact form (the form will be visible and fillable, but submissions aren't wired up yet — that needs a backend, built in a later phase)
- The Safety Intelligence Database
- The AI-Powered Research Assistant
- Bulletin and report publishing tools

Nothing is being removed or downgraded from the current site — these are capabilities the current site doesn't have either; they're listed on it as "planned," and this plan keeps them planned until their own phase.

## How Work Is Organized

The build is broken into 12 small, independently-verifiable steps — foundational work first (colors, fonts, images, shared header/footer), then one page at a time. Each step is checked against the live site before moving to the next, and the whole project is checked page-by-page one final time at the end. Nothing is marked "done" without being compared side-by-side against the current site first.

## Technology Being Used

- **Astro** — a modern website framework well-suited to content-heavy sites like this one, built for speed and search-engine visibility
- **Tailwind CSS** — for maintainable, consistent styling
- All text, images, and fonts are self-hosted in NFSINT's own codebase — no ongoing dependency on the no-code platform

## What Happens After This Phase

Once the rebuild is reviewed and approved, the code will move into a private GitHub repository under NFSINT's control. From there, the roadmap continues with the Safety Intelligence Database, the AI Research Assistant, and live form handling — each scoped and approved as its own phase, the same way this one was.
